# 番茄钟

一个本地小番茄钟,零第三方依赖。分三层:

- `timer.py`:纯逻辑,阶段状态机 + 倒计时(不读系统时钟,完全可单测)。
- `test_timer.py`:测试用例。
- `app.py`:Tkinter 图形界面。

## 图形界面

```bash
cd pomodoro
python app.py
```

弹出窗口后,点按钮或直接敲键盘:

| 按键 | 作用 |
|---|---|
| 空格 | 开始 / 暂停 |
| `R` | 重置 |

三个按钮:`开始/暂停`(同一按钮切换文案)、`重置`、`跳过`。

## 默认规则

| 阶段 | 默认时长 |
|---|---|
| 专注 | 25 分钟 |
| 短休 | 5 分钟 |
| 长休 | 15 分钟 |

每完成 **4 个专注**进入一次长休,休息结束回到专注。阶段结束时窗口响铃并弹窗提示。

## 跑测试

```bash
cd pomodoro
python test_timer.py       # 直接运行
# 或
pytest test_timer.py       # 用 pytest
```

## 说明

- 逻辑层不读真实时钟:`tick(dt)` 只按传入秒数递减,归零时返回
  `"work_finished"` / `"break_finished"` 事件,由界面层决定如何提示。
- 计时精度:界面用 `after(1000, ...)` 每秒驱动,受系统调度影响会有轻微漂移,
  实际精度约为"25 分钟"级别,不追求毫秒精确。
- 完成数不做持久化,重启即清零。
- 界面代码依赖 Tkinter。个别 Linux 发行版需先 `apt install python3-tk`;Windows/macOS 的官方 Python 一般自带。
